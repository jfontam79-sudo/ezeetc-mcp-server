# Morning Briefing

Run the TC's morning routine:

1. First, call `get_daily_briefing` to see what needs attention today
2. Then call `get_email_summary` to catch up on emails
3. Summarize everything in a clear, prioritized format:
   - 🔴 Urgent items (deadlines today, critical emails)
   - 🟡 Important items (deadlines this week, pending responses)
   - 🟢 Routine items (status updates, FYIs)

Present the briefing conversationally — this is how the TC starts their day. Be concise but thorough.
